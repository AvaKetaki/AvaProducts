# Cat Treat Spelling Game

A friendly browser game that helps children practice spellings by feeding a cat
treats for perfect answers.

## How to play

1. Open `index.html` in a web browser.
2. Choose a level.
3. Press **Start Game**.
4. Type the displayed word before the timer runs out.
5. If the word is typed correctly with no mistakes, the cat gets a treat. If the
   timer ends or a wrong letter is typed, the cat becomes sad and does not get fed.

The levels start with short basic words and progress to longer cat-themed words.

## Files

- `index.html` - Game markup and controls.
- `styles.css` - Child-friendly styling and cat illustration.
- `app.js` - Levels, timer, scoring, and game behavior.
